# Studio Da'lo — broader Oasis-inspired redesign

Updated 25 October 2026. This is the complete visual and interaction redesign, not only a name update.

- Image-filled wordmark with native-scroll opening into a full-screen architectural scene.
- A controlled still-image reel with pause/next and reduced-motion/data-saving behavior.
- Floating navigation, newly licensed typography, editorial gallery and animated filtering/reflow.
- Substantial project sheets: media/details side by side on desktop and image before details on phones.
- Eight original AI-generated fictional mood images, clearly labelled as demonstrations.
- Working filters/search, Wall/Index, project URLs/history, drawing enlargement and local-only enquiry preview.

## Put the new version on your existing website

Download studio-dalo-upload.zip and unzip it. Open your existing Netlify project imaginative-belekoy-450f0d, select Deploys, and drag the complete new studio-dalo folder into the manual deployment area. This updates your existing website address. Do not create a new project.

The GitHub download is not an automatic Netlify deployment. Your live website changes only after that upload finishes.
